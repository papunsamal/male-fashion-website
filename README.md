# Male Fashion Website 👔

A fully responsive Male Fashion E-Commerce Website built with HTML, CSS & JavaScript.

## 🌟 Features
- Smooth loader animation
- Sticky navbar with active links
- Hero section with full-screen background
- Live flash sale countdown timer
- Product cards with add-to-cart functionality
- Blog section with latest news
- Google Maps integration
- Contact form with validation
- Fully responsive (Mobile + Desktop)

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
